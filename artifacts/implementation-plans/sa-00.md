# Plan for Implementing Story: sa-00

Story: `artifacts/stories/sa-00-client-registry.md`

## Tasks
1. Domain: ClientApp model
  - Description: Add `Domain/Models/ClientApp.cs` (ClientId: Guid, Name: string, ClientSecret: string (hash), RedirectDomain: string, CreatedBy: Guid FK to User, CreatedOn: DateTime set internally to `DateTime.UtcNow` in the constructor).
  - Acceptance Criteria: Model compiles with no framework dependencies.
  - Status: Completed

2. Infrastructure: EF configuration and migration
  - Description: Add `DbSet<ClientApp>` to `ModelDbContext`; configure the ClientApp -> User (CreatedBy FK) relationship via `OnModelCreating`/entity configuration classes. Generate an EF Core migration.
  - Acceptance Criteria: `dotnet ef migrations add AddClientRegistry -p Infrastructure -s Api -o Database/Migrations` succeeds and produces the expected schema (ClientApps table); `dotnet build Identity.slnx` succeeds.
  - Status: Completed

3. App: secret hashing helper
  - Description: Add `App/ClientSecretHasher.cs` wrapping `Microsoft.AspNetCore.Identity.PasswordHasher<T>` with `Hash(secret)` and `Verify(secret, hash)` methods. No new package needed — `PasswordHasher<T>` is available via App's existing `FrameworkReference` to `Microsoft.AspNetCore.App`.
  - Acceptance Criteria: A hash of a known secret verifies successfully; a wrong secret fails verification.
  - Status: Completed

4. App: ClientRegistryService with enum validation result
  - Description: Add `App/ClientRegistryService.cs` exposing a method, e.g. `ValidateClient(Guid clientId, string redirectUri) : ClientValidationResult`, where `ClientValidationResult` is an enum (`Valid`, `UnknownClient`, `RedirectUriNotAllowed`). Backed by `ModelDbContext`, querying ClientApp and comparing the redirect URI's host against `RedirectDomain`.
  - Acceptance Criteria: Unregistered client id returns `UnknownClient`; registered client id with a redirect URI whose host doesn't match `RedirectDomain` returns `RedirectUriNotAllowed`; registered client id with a matching redirect URI returns `Valid`.
  - Status: Completed

5. App: register the service
  - Description: Register `ClientRegistryService` in `AppExtensions.AddApp()`.
  - Acceptance Criteria: Service resolves from DI in `Api`.
  - Status: Completed

6. App: environment-agnostic data seeding
  - Description: Generic seeding mechanism under `App/Seeding/`: `IDataSeeder` (interface with `SeedAsync(ModelDbContext)`, no environment concept), `ClientAppDevelopmentSeeder` (implementation inserting a `system` `User` and one `ClientApp` with `RedirectDomain` set to `localhost`, using the hasher from task 3), and `DataSeederExtensions.SeedDataAsync(this WebApplication app)` which just runs every registered `IDataSeeder` (assumes the schema already exists). Whether a given seeder runs at all is decided at DI registration time in `AddApp()` — `ClientAppDevelopmentSeeder` is only registered `if (environment.IsDevelopment())`; an "always" seeder would register unconditionally; a test-only seeder would register itself in a test project's own composition root. Applying migrations is a separate, explicit step (`App/DatabaseMigrator.cs`, `MigrateDatabaseAsync(this WebApplication app)`), called from `Program.cs` only when `app.Environment.IsDevelopment()`, before `SeedDataAsync()`. `Program.Main` changed to `async Task Main` to await both.
  - Acceptance Criteria: Running the app in Development creates the seed data exactly once (idempotent — checks for existing data before inserting); running with a non-Development environment does not seed; seeded data is queryable via `ModelDbContext`.
  - Status: Completed

7. Update story status
  - Description: Mark `sa-00-client-registry.md` status as implemented once tasks 1-6 are verified.
  - Acceptance Criteria: Story file status field updated.
  - Status: Not Started

## Excludes
- Login flow / OAuth authorization code flow.
- Admin UI for managing client app registrations (sa-01).
- Client secret rotation.
- Any API/controller endpoint for registering client apps (registration is dev-seed only per this plan).
